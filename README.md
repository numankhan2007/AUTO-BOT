## <img src="https://media.giphy.com/media/iY8CRBdQXODJSCERIr/giphy.gif" width="30px"> &nbsp; About

> **Shadow System** is a production-ready, AI-powered Instagram group chat bot deployed as a fully serverless monorepo on **Cloudflare** — zero servers, zero credit cards, zero compromises.

Built with the **Solo Leveling**-inspired *Shadow System* persona, this bot brings AI intelligence directly into Instagram group chats with text generation (Gemini 2.5 Flash), image creation (Pollinations.ai), and automated welcome messages — all orchestrated through Meta's webhook infrastructure.

## <img src="https://media.giphy.com/media/du3J3cXyzhj75IOgvA/giphy.gif" width="30px"> &nbsp; Deployment

### <img src="https://cdn.simpleicons.org/cloudflare/F38020" width="18"/> &nbsp; Frontend → Cloudflare Pages

<details>
<summary><b>Option A: Git Integration (Recommended)</b> — Click to expand</summary>
<br/>

1. Push this repo to **GitHub** / **GitLab**
2. Go to [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create**
3. Connect your repository
4. Configure build settings:

| Setting | Value |
|:--------|:------|
| **Root directory** | `frontend` |
| **Build command** | `npm run build` |
| **Build output directory** | `dist` |

> ⚠️ Setting **Root directory** to `frontend` fixes the `ENOENT: Could not read package.json` error.

</details>

<details>
<summary><b>Option B: Manual Deploy via CLI</b> — Click to expand</summary>
<br/>

```bash
cd frontend
npm install && npm run build
npx wrangler pages deploy dist --project-name=shadow-system
```

</details>

<br/>

### <img src="https://cdn.simpleicons.org/python/3776AB" width="18"/> &nbsp; Backend → Cloudflare Python Worker

```bash
cd backend/worker

# ── Set production secrets (you'll be prompted for each value) ──
npx wrangler secret put GEMINI_KEY
npx wrangler secret put INSTA_TOKEN
npx wrangler secret put APP_SECRET
npx wrangler secret put VERIFY_TOKEN
npx wrangler secret put INSTAGRAM_ACCOUNT_ID
npx wrangler secret put BOT_USERNAME

# ── Deploy ──
uvx --from workers-py pywrangler deploy
```

> 🔗 Your webhook URL: `https://shadow-system.<your-subdomain>.workers.dev/webhook`

## <img src="https://media.giphy.com/media/jSKBmKkvo2dPQQtsR1/giphy.gif" width="30px"> &nbsp; Environment Variables

<div align="center">

| Variable | Required | Description |
|:---------|:--------:|:------------|
| `PAGE_ACCESS_TOKEN` / `INSTA_TOKEN` | ✅ | Long-lived Meta Page Access Token |
| `APP_SECRET` | ✅ | Meta App Secret (Settings → Basic) |
| `VERIFY_TOKEN` | ✅ | Custom webhook verification string |
| `INSTAGRAM_ACCOUNT_ID` | ✅ | Bot's Instagram account ID (numeric) |
| `GEMINI_API_KEY` / `GEMINI_KEY` | ✅ | Google AI Studio API key |
| `BOT_USERNAME` | ✅ | Instagram @username (without `@`) |
| `AI_COOLDOWN_SECONDS` | ❌ | Rate limit per user (default: `30`) |
| `TOKEN_REFRESH_DAYS` | ❌ | Token refresh interval (default: `50`) |
| `LOG_LEVEL` | ❌ | Logging level (default: `INFO`) |

</div>

> 💡 **Local dev**: Set in `backend/.env` — **Production**: Set via `npx wrangler secret put <KEY>`


## <img src="https://media.giphy.com/media/xUPGcMzwkOY01nj4KQ/giphy.gif" width="25px"> &nbsp; Known Gotchas

<div align="center">

| Issue | Status | Solution |
|:------|:------:|:---------|
| `ENOENT: Could not read package.json` | 🟡 | Set Pages **Root directory** to `frontend` |
| Bot is not admin | 🔴 | 403 error → Add bot as admin in group chat settings |
| Duplicate events | 🟢 | Meta sends at-least-once — acceptable for welcome messages |
| Token expired | 🟡 | Run `token_refresh.py` every 50 days, or use a System User token |
| Cold starts | 🟢 | First request ~1-2s after idle, subsequent calls are instant |
| Error 1101 | 🟢 | Fixed — Defensive `try/except` + list-of-tuples headers in Worker |
| Pyodide snapshot | 🟢 | JS proxies (`fetch`, `Headers`) lazy-imported inside async functions |

</div>
