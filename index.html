Privacy Policy

Effective Date: April 28, 2026 · Last Updated: April 28, 2026

🛡️

Quick Summary

Shadow System is an Instagram messaging bot. We only process messages to respond in group chats. We do not store, sell, or share your personal data with any third parties.

Section 1

Introduction

Shadow System ("we", "us", "our") operates as an automated messaging bot on the Instagram platform via the Meta Messenger API. This Privacy Policy explains how we collect, use, and protect information when you interact with Shadow System in Instagram group chats.

By interacting with Shadow System, you agree to the practices described in this policy.

Section 2

Information We Process

When you send a message in a group chat where Shadow System is present, we may process the following data solely to generate a response:

  • Message content — The text of messages directed at the bot (via @mention or /ask commands).
  • Sender identifier — Your Instagram-provided user ID (used only to route the reply to the correct thread).
  • Thread identifier — The group chat ID where the interaction occurs.

We do not collect your name, email, profile picture, follower list, or any data beyond what is needed to reply to your message.

Section 3

How We Use Your Information

All processed information is used exclusively for the following purposes:

  • Responding to messages — Your message text is forwarded to a language model (Google Gemini) to generate a contextual reply, which is then sent back to the group chat.
  • Image generation — If you use the /imagine command, your prompt text is sent to an image generation service to create and return an image.
  • Welcome messages — When new members join a group, an automated welcome message is posted.
Section 4

Data Storage & Retention

Shadow System does not store any message content, user data, or conversation history.

All message processing happens in real-time within a serverless Cloudflare Worker. Once a response is generated and delivered, the message data is immediately discarded. No databases, logs, or persistent storage of user content are maintained.

Section 5

Data Sharing & Third Parties

We do not sell, rent, trade, or share your personal data with any third parties.

The only external services that process data during a request are:

  • Meta (Instagram) API — To receive and send messages within the Instagram platform.
  • Google Gemini API — To generate AI-powered text responses. Google's API usage policies apply to data sent for processing.
  • Pollinations.ai — To generate images from text prompts when the /imagine command is used.
  • Cloudflare — Our hosting infrastructure provider. No user data is stored on Cloudflare beyond the duration of a single request.

Each of these services processes data only for the duration of the request and in accordance with their own privacy policies.

Section 6

Data Security

We implement the following security measures:

  • All communication is encrypted via HTTPS/TLS 1.3.
  • Webhook payloads from Meta are verified using HMAC-SHA256 signature validation.
  • API keys and secrets are stored securely as encrypted environment variables, never in source code.
  • The bot runs on Cloudflare's serverless infrastructure with zero persistent state.
Section 7

Children's Privacy

Shadow System does not knowingly collect or process data from children under the age of 13. If you believe a child has interacted with our service, please contact us so we can take appropriate action.

Section 8

Your Rights

Since we do not store any personal data, there is no user data to access, modify, or delete. However, you have the right to:

  • Stop interaction — Simply stop mentioning or sending commands to the bot.
  • Remove the bot — Group administrators can remove Shadow System from any group chat at any time.
  • Request information — Contact us if you have questions about how your data is processed.
Section 9

Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected on this page with an updated "Last Updated" date. Continued interaction with Shadow System after changes constitutes acceptance of the revised policy.
